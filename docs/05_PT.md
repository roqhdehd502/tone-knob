# Tone Knob — 프레젠테이션 자료

> **최종 업데이트**: 2026-07-13

---

## 1. 한 줄 소개

> **기타리스트를 위한 탭 제작 + 실시간 온라인 합주 통합 플랫폼**

---

## 2. 문제 정의

기타리스트들은 현재 두 가지 근본적인 불편을 겪고 있습니다.

| 문제            | 현실                                                                   |
| --------------- | ---------------------------------------------------------------------- |
| **타브 제작**   | Guitar Pro(오프라인), Ultimate Guitar(읽기 전용) — 웹 기반 편집기 없음 |
| **온라인 합주** | JamKazam은 합주 특화지만 타브 기능 없음. Zoom은 오디오 지연이 심각     |

두 기능을 하나의 플랫폼에서 제공하는 서비스는 존재하지 않습니다.

---

## 3. 솔루션

Tone Knob은 다음 세 축을 하나로 통합합니다.

```
┌─────────────────────────────────────────────────┐
│                  Tone Knob                      │
│                                                 │
│  [타브 에디터]  ←→  [실시간 합주]  ←→  [커뮤니티]  │
│   드래그 & 드롭       WebRTC 기반       마켓플레이스  │
│   AI 자동 생성        합주방 동기화      팔로우/피드   │
└─────────────────────────────────────────────────┘
```

---

## 4. 핵심 기능

### 4.1 타브 에디터

- **드래그 앤 드롭 편집** — 마우스로 줄·프렛 위치에 음표 배치
- **실시간 오디오 미리듣기** — Web Audio API + Tone.js 기반 사운드폰트 재생
- **연습 모드** — 반복 구간 설정, 속도 조절, 메트로놈
- **버전 관리** — 변경사항 자동 스냅샷 (Git 스타일 이력)
- **AI 타브 생성** — 프롬프트 입력 → Claude API → TabDocument 자동 생성
- **오디오 → 타브** — 음원 업로드 → Basic Pitch(ML) → 자동 채보

### 4.2 실시간 합주방

- **WebRTC P2P 오디오** — Mediasoup SFU, Opus 코덱
- **타브 동기화** — 방장 재생 컨트롤에 따른 모든 참가자 동기화
- **협업 편집** — Operational Transformation 기반 동시 타브 편집
- **개별 음량 조절** — 참가자별 볼륨 믹서
- **실시간 채팅** — Socket.io 기반

### 4.3 커뮤니티 & 마켓플레이스

- **타브 공유/검색** — 공개 타브 피드, 아티스트/장르 필터
- **소셜 기능** — 팔로우, 좋아요, 댓글, 리뷰/별점
- **Knob 내부 재화** — 활동 적립, 타브 구매에 사용
- **마켓플레이스** — 타브 판매/구매, 판매자 정산
- **뱃지 시스템** — 활동 기반 자동 지급 15종

## 5. 기술 스택

### 프론트엔드

| 구분       | 기술                             |
| ---------- | -------------------------------- |
| 프레임워크 | React 19 + React Router V7 (SSR) |
| 언어       | TypeScript                       |
| 스타일     | Tailwind CSS v4 + Radix UI       |
| 오디오     | Web Audio API + Tone.js          |
| 실시간     | Socket.io Client + WebRTC        |
| 상태 관리  | React Query + Zustand            |

### 백엔드 (MSA)

| 서비스           | 역할                             | 포트                 |
| ---------------- | -------------------------------- | -------------------- |
| gateway          | HTTP API Gateway, Swagger, 인증  | :3000                |
| auth-svc         | 인증, OAuth2                     | TCP :3001            |
| tab-svc          | 타브 CRUD, 버전, 포크            | TCP :3002            |
| jam-svc          | 합주방, 협업 편집, WebSocket     | TCP :3003 / WS :3004 |
| community-svc    | 커뮤니티, 알림, 뱃지             | TCP :3005            |
| marketplace-svc  | 결제, Knob, 정산                 | TCP :3006            |
| subscription-svc | 구독 플랜                        | TCP :3007            |
| media-svc        | 파일 업로드                      | TCP :3008            |
| ai-svc           | AI 작업 디스패치                 | TCP :3009            |
| **ml-server**    | FastAPI, Basic Pitch, Claude API | HTTP :8001           |

### 인프라

| 구분          | 기술                                     |
| ------------- | ---------------------------------------- |
| DB            | Supabase PostgreSQL 17 (22 테이블, RLS)  |
| 캐시          | Redis 7                                  |
| 스토리지      | Supabase Storage                         |
| 배포          | OCI Free Tier ARM (Ampere A1 4vCPU/24GB) |
| 역방향 프록시 | Nginx + Let's Encrypt                    |
| CI/CD         | GitHub Actions (Blue-Green)              |
| 모노레포      | Turborepo                                |

## 6. 시스템 아키텍처

```
[Browser / App]
      │
      ▼
[Nginx : 443]  ──────────────────────────────────────
      │
      ▼
[Gateway :3000]  (JWT 검증, REST 라우팅)
      │
      ├─── TCP ──► auth-svc         (인증/유저)
      ├─── TCP ──► tab-svc          (타브)
      ├─── TCP ──► jam-svc ◄── WS ─ (합주/협업)
      ├─── TCP ──► community-svc    (커뮤니티)
      ├─── TCP ──► marketplace-svc  (결제/마켓)
      ├─── TCP ──► subscription-svc (구독)
      ├─── TCP ──► media-svc        (미디어)
      └─── TCP ──► ai-svc
                      │
                      ▼ HTTP POST /jobs
                  [ml-server :8001]  (FastAPI)
                      │
                      ├── Claude API  (TAB_GENERATION)
                      └── Basic Pitch (AUDIO_EXTRACTION)
                      │
                      ▼ Webhook
                  [Gateway /api/ai-gen/webhook/{id}]
```

## 7. AI 기능 상세

| 기능            | 방식                               | 인프라 요구           |
| --------------- | ---------------------------------- | --------------------- |
| 프롬프트 → 타브 | Claude API (`claude-sonnet-5`)     | 외부 API (GPU 불필요) |
| 오디오 → 타브   | Basic Pitch (Spotify, TFLite 기반) | CPU-only, ARM64 호환  |

- ML 서버는 FastAPI (Python) + uvicorn으로 구동
- API 키 미설정 시 서버는 정상 기동, `/health`에서 기능 활성화 여부 표시
- OCI ARM 인스턴스에서 GPU 없이 동작 가능한 모델만 선택
