# 기획안

## 1. 프로젝트 개요

### 1.1 프로젝트명

톤 노브 (Tone Knob)

### 1.2 목표

음악을 사랑하는 사람들이 타브를 제작하고, 실시간으로 온라인 합주를 즐길 수 있는 통합 플랫폼 구축

### 1.3 핵심 가치

- **접근성:** 누구나 쉽게 타브를 만들고 공유할 수 있는 직관적인 인터페이스
- **실시간성:** 지연 없는 온라인 합주 경험 제공
- **커뮤니티:** 음악가들이 연결되고 협업할 수 있는 생태계 조성

## 2. 개발 단계별 계획

### Phase 1: 타브 제작 기능 (1-6개월)

### 핵심 기능

- **드래그 앤 드롭 타브 에디터**
  - 마우스 기반 직관적 인터페이스
  - 기타, 베이스, 드럼 등 다양한 악기 지원
  - 숫자 입력 및 키보드 단축키 지원
- **실시간 음원 재생**
  - Web Audio API를 활용한 실시간 사운드 생성
  - 메트로놈 및 템포 조절 기능
  - 반복 구간 설정 및 연습 모드
- **AI 기반 타브 자동 생성**
  - 오디오/MIDI 파일 업로드 기능
  - 머신러닝 모델을 통한 자동 타브 변환
  - 사용자 피드백을 통한 정확도 개선
- **템플릿 라이브러리**
  - 장르별 타브 템플릿 제공 (록, 재즈, 블루스 등)
  - 초보자를 위한 가이드 포함

### 부가 기능

- 버전 관리 시스템 (Git 스타일)
- 멀티 악기 동시 편집
- PDF/이미지 내보내기

### 기술 스택

- 프론트엔드: React (React Router V7), TypeScript, Web Audio API
- 백엔드: Node.js (NestJS), PostgreSQL (Supabase)
- AI: TensorFlow

### Phase 2: 실시간 온라인 합주 기능 (7-12개월)

### 핵심 기능

- **저지연 오디오 스트리밍**
  - WebRTC 기반 P2P 연결
  - 목표: 50ms 이하의 지연시간
  - 네트워크 상태에 따른 자동 품질 조절
- **가상 합주실**
  - 방 생성 및 초대 시스템
  - 최대 8명까지 동시 합주 지원
  - MIDI 컨트롤러, 오디오 인터페이스와의 연동을 통한 악기 합주 기능 지원
  - 공개/비공개 방 설정
- **동기화된 타브 스크롤**
  - 모든 참가자의 타브 자동 동기화
  - 방장의 재생 컨트롤에 따른 일괄 제어
- **파트별 음량 조절**
  - 개별 믹서 인터페이스
  - 자신의 파트 강조 기능
  - 전체 밸런스 프리셋 제공
- **녹음 및 믹싱**
  - 세션 자동 녹음
  - 파트별 트랙 분리 저장
  - 간단한 믹싱 도구 제공

### 부가 기능

- 비디오 채팅 통합 (선택적 활성화)
- 가상 이펙터 보드 (리버브, 딜레이, 디스토션 등)
- AI 반주 봇 (부족한 파트 자동 연주)
- 연습 모드 (구간 반복, 템포 조절)
- 라이브 공연 모드 (실시간 스트리밍)

### 기술 스택

- 실시간 통신: WebRTC, [Socket.io](http://Socket.io)
- 미디어 서버: Mediasoup/Janus
- 스트리밍: HLS/DASH
- 인프라: AWS/GCP, CDN

## 3. 커뮤니티 및 수익화 전략

### 3.1 커뮤니티 기능

- **타브 마켓플레이스**
  - 사용자 제작 타브 공유 및 판매
  - 무료/유료 타브 구분
  - 평점 및 리뷰 시스템
- **협업 편집 모드**
  - Google Docs 스타일의 실시간 공동 편집
  - 댓글 및 제안 기능
- **게이미피케이션**
  - 연주 시간, 완성한 곡 수에 따른 레벨 시스템
  - 업적 및 배지
  - 주간/월간 챌린지

### 3.2 수익 모델

- **프리미엄 구독**
  - 무료: 타브 월 3회 제작, 합주방 무제한 참여, 공개 타브 열람
  - 프리미엄: 타브 무제한 제작, AI 자동 생성, 고급 이펙트, 광고 제거
  - 가격: 월 9,900원 / 연 99,000원
- **내부 재화 시스템 (Knob)**
  - 활동 기반 마일리지 적립 (타브 제작, 합주 참여, 커뮤니티 활동 등)
  - 마켓플레이스 타브 구매 시 Knob 재화로 결제
- **마켓플레이스 수수료**
  - 유료 타브 판매 시 30% 수수료 (Knob 재화 기준)
- **기업용 라이선스**
  - 음악 학원, 교육 기관용 B2B 서비스
- **광고 (무료 사용자 대상)**
  - 비침해적 배너 광고

## 4. 기술적 과제 및 해결 방안

### 4.1 저지연 오디오 전송

**과제:** 실시간 합주를 위한 50ms 이하 지연시간 달성

**해결방안:**

- WebRTC P2P 연결 우선 사용
- 지역별 TURN 서버 배치
- 네트워크 상태에 따른 버퍼 크기 자동 조절
- Opus 코덱을 활용한 저지연 오디오 인코딩

### 4.2 네트워크 최적화

**과제:** 전 세계 사용자 간 원활한 연결

**해결방안:**

- 주요 지역별 엣지 서버 배치 (아시아, 유럽, 북미)
- CDN을 통한 정적 콘텐츠 배포
- 사용자 위치 기반 최적 서버 자동 선택

### 4.3 저작권 관리

**과제:** 공유되는 타브의 저작권 문제

**해결방안:**

- 저작권 신고 시스템 구축
- 자동 필터링 알고리즘 개발
- 원작자 표기 의무화
- 음악 저작권 단체와 협력 모델 검토

## 5. 개발 일정 및 마일스톤

### Phase 1 (1-6개월)

- 1개월: 기본 UI/UX 설계 및 프로토타입
- 2-3개월: 타브 에디터 핵심 기능 개발
- 4개월: 실시간 음원 재생 및 템플릿 라이브러리
- 5개월: AI 자동 생성 기능 개발 및 테스트
- 6개월: 베타 테스트 및 피드백 반영

### Phase 2 (7-12개월)

- 7-8개월: WebRTC 기반 실시간 통신 인프라 구축
- 9개월: 가상 합주실 및 동기화 기능 개발
- 10개월: 녹음, 믹싱, 이펙터 기능 개발
- 11개월: AI 반주 봇 및 부가 기능 개발
- 12개월: 통합 테스트 및 정식 출시

## 8. 리스크 및 대응 방안

### 8.1 기술적 리스크

**리스크:** 저지연 목표 미달성

**대응:** 초기에는 지연시간 허용 범위를 넓히고, 점진적으로 최적화. 사용자에게 네트워크 품질 가이드 제공

### 8.2 시장 리스크

**리스크:** 기존 경쟁 서비스(Guitar Pro, Ultimate Guitar 등)와의 차별화 부족

**대응:** 실시간 합주 기능에 집중하여 차별화. 커뮤니티 중심의 생태계 구축

### 8.3 법률 리스크

**리스크:** 저작권 침해 소송

**대응:** 명확한 이용약관 및 저작권 정책 수립. 신고 시스템 적극 운영
