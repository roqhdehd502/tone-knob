# Tone Knob – MVP 기능 명세서 (PRD)

## 프로젝트 개요

### 프로젝트 명
Tone Knob

### 한 줄 정의
실시간 악보 기반 온라인 합주 플랫폼

### 서비스 목적
- 물리적 공간 제약 없이 합주 환경 제공
- 악보 중심의 협업 음악 환경 구축
- 연습, 교육, 협업이 가능한 온라인 합주 공간 제공

---

## 타겟 사용자

### Primary User
- 전자 악기 연주자 (기타, 베이스, 키보드, 드럼, MIDI)
- 합주 경험을 원하는 개인 연주자
- 밴드 구성원

### Secondary User
- 음악 강사
- 음악 학원
- 온라인 음악 교육 플랫폼

---

## 문제 정의 (Problem Statement)

1. 합주 공간의 물리적 제약
2. 온라인 합주의 레이턴시 문제
3. 악보 공유의 비효율성
4. 실시간 협업 연습 환경 부재

---

## 해결 방향 (Solution)

Tone Knob은 다음 구조로 문제를 해결한다:

- 실시간 오디오 합주 환경 제공
- 악보 중심 UX 설계
- 악보 동기화 기반 합주 구조
- 메트로놈 + BPM 기반 타이밍 동기화
- 실시간 가이드 시스템

---

# MVP 범위 정의

## MVP 목표

"실제 합주가 가능한 최소 기능 서비스"

### 핵심 목표
1. 사람들이 실제로 동시에 연주할 수 있어야 한다
2. 악보를 보며 함께 연주할 수 있어야 한다
3. 합주 타이밍이 유지되어야 한다

# 기능 명세

## 1. 사용자 시스템

### 1.1 회원가입/로그인
- 이메일 기반 회원가입
- 소셜 로그인(후순위)

### 1.2 사용자 프로필
- 닉네임
- 주 악기 선택
- 오디오 장치 설정

---

## 2. 방(Room) 시스템

### 2.1 방 생성
필드:
- 방 이름
- BPM
- Key
- Time Signature
- Sync Mode (metronome/free)
- 공개/비공개 설정

### 2.2 방 참가
- 초대 링크
- 방 코드

### 2.3 방 역할
- Host
- Player

---

## 3. 실시간 합주 시스템

### 3.1 오디오 입력
- 마이크
- 오디오 인터페이스
- MIDI 입력(후순위)

### 3.2 오디오 스트리밍
- WebRTC 기반
- 실시간 오디오 전송

### 3.3 오디오 믹싱
- 클라이언트 믹싱
- 볼륨 조절
- 뮤트 기능

---

## 4. 악보 시스템

### 4.1 악보 업로드
지원 포맷:
- PDF
- 이미지(PNG, JPG)
- MusicXML

### 4.2 악보 렌더링
- SVG 기반 뷰어
- 확대/축소
- 페이지 이동

### 4.3 악보 공유
- 방 단위 악보 공유
- 실시간 페이지 동기화
- 스크롤 동기화

---

## 5. 동기화 시스템

### 5.1 BPM 동기화
- 방 BPM 기준
- 메트로놈 기반 동기화

### 5.2 메트로놈
- 공통 메트로놈
- 오디오/시각 표시

---

## 6. 가이드 시스템

### 6.1 연주 위치 가이드
- 현재 마디 표시
- 현재 박(beat) 표시
- 하이라이트 UI
