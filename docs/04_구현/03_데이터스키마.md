# 데이터 스키마

> **최종 업데이트**: 2026-07-13
>
> 전체 서비스는 **Supabase PostgreSQL 17** 공유 DB를 사용합니다.
> 각 마이크로서비스는 독립 커넥션 풀을 통해 접속하며, 필요한 테이블만 참조합니다.
> 서비스별 `user.entity.ts`, `tab.entity.ts` 등은 외래키 조인을 위한 로컬 참조 엔티티이며, 실제 마스터 데이터는 `auth-svc`(users), `tab-svc`(tabs)에서 관리합니다.

## 1. auth-svc

### `users`

사용자 계정 마스터 테이블. 소셜 로그인(Google, GitHub)과 이메일/비밀번호 로그인을 모두 지원합니다.

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| `id` | UUID | PK | 사용자 고유 ID |
| `email` | VARCHAR(255) | UNIQUE, NOT NULL | 이메일 |
| `username` | VARCHAR(50) | UNIQUE, NOT NULL | 사용자명 |
| `provider` | VARCHAR(50) | DEFAULT `'local'` | 인증 공급자 (`local` / `google` / `github`) |
| `provider_id` | VARCHAR(255) | nullable | 소셜 공급자 고유 ID |
| `password_hash` | VARCHAR(255) | nullable, SELECT 제외 | bcrypt 해시 (소셜 로그인 시 null) |
| `knob_balance` | INT | DEFAULT 0 | Knob 재화 잔액 |
| `display_name` | VARCHAR(100) | nullable | 표시 이름 |
| `avatar_url` | TEXT | nullable | 프로필 이미지 URL |
| `bio` | VARCHAR(500) | nullable | 자기소개 |
| `role` | VARCHAR(20) | DEFAULT `'user'` | 권한 (`user` / `admin`) |
| `subscription_tier` | VARCHAR(20) | DEFAULT `'free'` | 구독 등급 (`free` / `premium` / `pro`) |
| `subscription_expires_at` | TIMESTAMP | nullable | 구독 만료 시각 |
| `created_at` | TIMESTAMP | NOT NULL | 가입 일시 |
| `updated_at` | TIMESTAMP | NOT NULL | 최종 수정 일시 |

## 2. tab-svc

### `tabs`

기타 타브 마스터 테이블. 실제 타브 데이터는 `content` JSONB 컬럼에 `TabDocument` 구조로 저장됩니다.

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| `id` | UUID | PK | 타브 고유 ID |
| `user_id` | UUID | FK → users.id | 작성자 |
| `title` | VARCHAR(200) | NOT NULL | 제목 |
| `artist` | VARCHAR(100) | nullable | 아티스트명 |
| `content` | JSONB | NOT NULL | TabDocument (sections, measures, notes) |
| `thumbnail_url` | TEXT | nullable | 썸네일 URL |
| `is_public` | BOOLEAN | INDEX, DEFAULT false | 공개 여부 |
| `view_count` | INT | DEFAULT 0 | 조회수 |
| `like_count` | INT | DEFAULT 0 | 좋아요 수 |
| `download_count` | INT | DEFAULT 0 | 다운로드 수 |
| `price` | INT | DEFAULT 0 | 판매 가격 (Knob) |
| `created_at` | TIMESTAMP | NOT NULL | 생성 일시 |
| `updated_at` | TIMESTAMP | NOT NULL | 최종 수정 일시 |

**TabDocument 구조 (content JSONB)**

```jsonc
{
  "title": "string",
  "artist": "string",
  "tuning": ["E", "B", "G", "D", "A", "E"],   // 줄 튜닝 (6줄)
  "bpm": 120,
  "timeSignature": [4, 4],
  "sections": [
    {
      "id": "uuid",
      "name": "Intro",
      "measures": [
        {
          "id": "uuid",
          "notes": [
            {
              "id": "uuid",
              "string": 0,      // 0=high E, 5=low E
              "fret": 0,        // 0–22
              "duration": 0.25, // 온음표 기준 분수 (0.25=4분음표)
              "position": 0.0   // 마디 내 위치 (0.0–1.0)
            }
          ]
        }
      ]
    }
  ]
}
```

## 7. ai-svc

### `ai_jobs`

AI 타브 생성 및 오디오 추출 작업 큐. ML 서버 디스패치 상태를 추적합니다.

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| `id` | UUID | PK | 작업 고유 ID |
| `user_id` | UUID | INDEX, FK → users.id | 요청자 |
| `type` | ENUM | NOT NULL | `tab_generation` / `audio_extraction` |
| `status` | ENUM | DEFAULT `queued` | `queued` / `processing` / `completed` / `failed` |
| `input_data` | JSONB | NOT NULL | 작업 입력 (프롬프트, 오디오 URL 등) |
| `output_data` | JSONB | nullable | 작업 결과 (TabDocument) |
| `error_message` | TEXT | nullable | 실패 시 에러 메시지 |
| `progress` | INT | DEFAULT 0 | 진행률 (0–100) |
| `external_job_id` | VARCHAR(255) | nullable | ML 서버 내부 작업 ID |
| `created_at` | TIMESTAMP | NOT NULL | 요청 일시 |
| `updated_at` | TIMESTAMP | NOT NULL | 최종 상태 갱신 일시 |

**AI 작업 흐름**

```
[사용자 요청]
    ↓
ai-svc → POST /jobs (ML 서버)
    ↓ 202 Accepted (즉시 응답)
ML 서버 백그라운드 처리
    ↓ 완료/실패
ML 서버 → POST /api/ai-gen/webhook/{jobId} (gateway)
    ↓
ai-svc 상태 업데이트 (completed / failed)
```
