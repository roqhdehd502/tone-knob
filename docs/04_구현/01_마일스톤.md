# 현재 아키텍처 요약

```
tone-knob/
├── frontend/               # React Router V7 (SSR) + React 19 + Tailwind v4
├── services/
│   ├── gateway/            # HTTP :3000 — API Gateway (Swagger, 인증, 프록시)
│   ├── auth-svc/           # TCP :3001 — 인증/사용자 관리
│   ├── tab-svc/            # TCP :3002 — 타브 CRUD, 포크, 퍼블리시
│   ├── jam-svc/            # TCP :3003 + WS :3004 — 합주/협업
│   ├── community-svc/      # TCP :3005 — 커뮤니티, 알림, 리뷰, 뱃지
│   ├── marketplace-svc/    # TCP :3006 — 마켓, 결제, 정산, Knob
│   ├── subscription-svc/   # TCP :3007 — 구독 플랜
│   ├── media-svc/          # TCP :3008 — 미디어 업로드/변환
│   └── ai-svc/             # TCP :3009 — AI 타브 생성/오디오 추출
├── packages/shared/        # 공유 DTO, 이벤트 상수 (@tone-knob/shared)
├── supabase/               # DB 마이그레이션 + 시드 데이터
└── docs/                   # 기획/분석/설계/구현 문서
```

- **DB**: Supabase PostgreSQL 17 (공유 DB, 서비스별 독립 커넥션 풀)
- **서비스 간 통신**: NestJS TCP (request-reply) + EventPattern (이벤트 드리븐)
- **인증**: JWT (access 15m, refresh 7d) + OAuth2 (Google, GitHub 조건부)
- **빌드**: Turborepo 모노레포

# 개발 환경 빠른 시작

```bash
# 1. 의존성 설치
npm install

# 2. 환경변수 설정 (각 서비스 .env.sample 참고)
#    필수: DATABASE_URL, JWT_SECRET (auth-svc, gateway, jam-svc 동일 값)

# 3. DB 마이그레이션 적용
psql "$DATABASE_URL" -f supabase/migrations/20240101000000_initial_schema.sql
psql "$DATABASE_URL" -f supabase/migrations/20240102000000_add_oauth_knob_columns.sql
psql "$DATABASE_URL" -f supabase/migrations/20240103000000_add_badges_tables.sql
psql "$DATABASE_URL" -f supabase/migrations/20240104000000_add_knob_transactions_extend_notification_enum.sql

# 4. 시드 데이터 (선택)
psql "$DATABASE_URL" -f supabase/seed.sql

# 5. 전체 서비스 실행
npm run dev

# 6. 접속
# Frontend: http://localhost:5173
# Gateway (Swagger): http://localhost:3000/api/docs
```
