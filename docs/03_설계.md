# 프론트엔드 설계

## 1. 기술 스택

### 핵심 프레임워크

- **React 19+:** 컴포넌트 기반 UI 개발
- **TypeScript:** 타입 안정성 확보
- **React Router V7:** SSR/SSG 지원, 최적화된 라우팅

### 상태 관리

- **React Query:** 서버 상태 관리 및 캐싱

### UI/UX 라이브러리

- **Tailwind CSS:** 유틸리티 기반 스타일링
- **Radix UI:** 접근성 높은 헤드리스 컴포넌트
- **Framer Motion:** 부드러운 애니메이션

### 오디오 처리

- **Web Audio API:** 브라우저 네이티브 오디오 처리
- **Tone.js:** 음악 이론 기반 오디오 신호 처리
- **Pizzicato.js:** 이펙터 및 오디오 효과

### 실시간 통신

- **WebRTC:** P2P 오디오 스트리밍
- **Socket.io Client:** 실시간 데이터 동기화
- **MediaStream API:** 오디오 입력 처리

## 4. 주요 기능 구현 전략

### 4.1 드래그 앤 드롭 타브 편집

- **react-dnd** 또는 **@dnd-kit** 사용
- 각 음표를 드래그 가능한 아이템으로 구현
- 줄과 프렛 위치를 드롭 존으로 설정
- 드래그 중 미리보기 표시
- 스냅 기능으로 정확한 위치 배치

### 4.2 실시간 재생 및 미리듣기

- Web Audio API의 AudioContext로 음원 재생
- 각 음표를 스케줄링하여 정확한 타이밍 보장
- 재생 커서를 requestAnimationFrame으로 부드럽게 이동
- 루프 구간 설정 및 템포 조절 기능

### 4.3 반응형 디자인

- **데스크톱 우선:** 타브 편집은 큰 화면에 최적화
- **태블릿:** 터치 제스처로 줌/팬 지원
- **모바일:** 뷰어 모드 위주, 간단한 편집만 지원

### 4.4 성능 최적화

- **가상 스크롤링:** react-window로 대량의 마디 렌더링
- **메모이제이션:** React.memo, useMemo로 불필요한 리렌더링 방지
- **Web Worker:** 타브 파싱/직렬화를 백그라운드 스레드에서 처리
- **Code Splitting:** 에디터와 합주방을 별도 번들로 분리
- **이미지 최적화:** Next.js Image 컴포넌트 활용

## 5. 보안 고려사항

- **XSS 방지:** 사용자 입력 sanitize (DOMPurify)
- **CSRF 방지:** SameSite 쿠키 설정
- **인증 토큰:** httpOnly 쿠키에 저장
- **WebRTC 보안:** TURN 서버로 IP 노출 최소화

## 6. 테스트 전략

- **단위 테스트:** Vitest로 유틸리티 함수 및 훅 테스트
- **컴포넌트 테스트:** React Testing Library
- **E2E 테스트:** Playwright로 주요 사용자 시나리오 검증
- **오디오 테스트:** 수동 테스트 + 지연시간 모니터링

```sql
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
```

### Tabs 테이블

```sql
CREATE TABLE tabs (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  title VARCHAR(200) NOT NULL,
  artist VARCHAR(100),
  content JSONB NOT NULL, -- 타브 데이터 (JSON)
  thumbnail_url TEXT,
  is_public BOOLEAN DEFAULT false,
  view_count INTEGER DEFAULT 0,
  like_count INTEGER DEFAULT 0,
  download_count INTEGER DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_tabs_user_id ON tabs(user_id);
CREATE INDEX idx_tabs_public ON tabs(is_public) WHERE is_public = true;
```

### Jamrooms 테이블

```sql
CREATE TABLE jamrooms (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  host_id UUID REFERENCES users(id) ON DELETE CASCADE,
  name VARCHAR(100) NOT NULL,
  description TEXT,
  max_participants INTEGER DEFAULT 8,
  is_public BOOLEAN DEFAULT true,
  password_hash VARCHAR(255),
  current_tab_id UUID REFERENCES tabs(id),
  status VARCHAR(20) DEFAULT 'waiting', -- waiting, active, ended
  created_at TIMESTAMP DEFAULT NOW(),
  ended_at TIMESTAMP
);

CREATE INDEX idx_jamrooms_public ON jamrooms(is_public, status);
```

### Jamroom_Participants 테이블

```sql
CREATE TABLE jamroom_participants (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),

  is_muted BOOLEAN DEFAULT false,

  left_at TIMESTAMP,
```

## 7. 성능 최적화

### 데이터베이스 최적화

- **인덱싱:** 자주 조회되는 컬럼에 인덱스 추가
- **Connection Pooling:** pg-pool로 연결 재사용
- **쿼리 최적화:** N+1 문제 해결, JOIN 최소화
- **파티셔닝:** 타브 버전 테이블 날짜별 파티셔닝

### 캐싱 전략

- **타브 데이터:** Redis에 1시간 캐싱
- **사용자 프로필:** Redis에 30분 캐싱
- **합주방 상태:** Redis에 실시간 저장 (TTL 1시간)
- **CDN:** 정적 리소스 및 썸네일 캐싱

### 실시간 통신 최적화

- **Opus 코덱:** 저지연 고품질 오디오
- **DTX (Discontinuous Transmission):** 무음 구간 전송 생략
- **Adaptive Bitrate:** 네트워크 상태에 따라 비트레이트 조절
- **Jitter Buffer:** 패킷 도착 시간 변동 보정

## 8. 보안 설계

### 인증 및 인가

- **JWT:** Access Token (15분), Refresh Token (7일)
- **httpOnly 쿠키:** Refresh Token 저장
- **RBAC:** 역할 기반 접근 제어 (user, premium, admin)

### API 보안

- **Rate Limiting:** express-rate-limit으로 요청 제한
- **Input Validation:** Joi 또는 Zod로 입력 검증
- **SQL Injection 방지:** Parameterized Queries
- **CORS:** 허용된 도메인만 접근

### 데이터 보호

- **비밀번호:** bcrypt (cost factor 12)
- **민감 정보:** 환경 변수로 관리 (AWS Secrets Manager)
- **HTTPS:** TLS 1.3 강제
- **데이터 암호화:** 저장 데이터 AES-256 암호화
